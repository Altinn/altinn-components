# DialogActions

DialogActions renders the actions (GUI actions) a user can perform on a dialog. Every visible action is rendered as its own button, sorted by priority: `primary`, `secondary` and then `tertiary`.

<Canvas of={DialogActions.Default} />

<Controls />

## No grouping into a menu

Actions are never collapsed into a dropdown menu, no matter how many there are. A dialog has at most 6 actions, which is few enough to show all of them.

<Canvas of={DialogActions.MaxActions} />

Adding or removing an action, for example when the dialog is moved to the bin and a `Slett` action appears, keeps the layout stable.

<Canvas of={DialogActions.ActionAddedAtRuntime} />

## Priority

A dialog usually has a single primary action. The primary action is rendered as a solid button, all others as outline buttons.

<Canvas of={DialogActions.PrimaryOnly} />

<Canvas of={DialogActions.SecondaryOnly} />

<Canvas of={DialogActions.WithTertiary} />

Actions are sorted by priority regardless of the order they are passed in.
